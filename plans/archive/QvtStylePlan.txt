Context

The qvt render mode (Vue 3.5.44 + Quasar 2.35.1, /qapps) was ported from the Java tree's Quasar 1 / Vue 2 client. The macros
(ScreenQvt.js, ScreenQvtStatic.js), the widget wrappers and shell (WebrootVue.qvt.js) and the style sheet (WebrootVue.qvt.css)
carried the Quasar 1 choices over: every button is dense outline, the field label is pushed into the outline border by ~20 lines of
CSS, cards are made transparent, the table CSS is a copy of Quasar 1.12 rules, and the shell uses a hand-made menu column instead of
a drawer. Some overrides target selectors that no longer exist in Quasar 2 (.q-btn__wrapper). The goal is a clean, modern,
consistent UI using what Quasar 2.35 provides natively, with fewer overrides.

Decisions already taken with the user:
- Screen links in form-list cells become plain text links; elsewhere links become tonal (soft tinted) buttons. Transition
  links stay buttons everywhere.
- Field labels: Quasar native stacked label inside the outlined box; remove the notch CSS.
- Form submit keeps the outline-until-changed signal.

Buttons (macros + components)

Every q-btn is dense outline no-caps (ScreenQvt.js submit, reset_, linkElement, linkForm, dynamicDialog, nav,
pageSizeMenu, savedFindsDialogBody, findDialogBody, textDialog, buttonMenuMacro; mirrored in ScreenQvtStatic.js lines
522-1399; components m-container-dialog, m-dynamic-dialog, m-form-column-config, m-form-paginate, m-form-go-page,
m-qapps-root). Outline = transparent background, so a list row with four links reads as four hollow boxes.

Field widgets (WebrootVue.qvt.js)

- All wrappers: keep dense outlined stack-label; add hide-bottom-space and no-error-icon; drop style="max-width:max-content" on
  m-date-time in favor of input-class/size.
- m-drop-down: use use-chips for multiple (remove the custom q-chip prepend and hide-selected toggle); for single with
  use-input add fill-input hide-selected; keep options-dense, behavior="menu", clearable. The show-not checkbox in the
  after slot becomes a q-toggle dense size="xs" label="Not" in append (removes the 10px label CSS).
- m-check / m-radio with options: m-field wrapper switches to borderless so a group of radios is not boxed like an input;
  inner q-option-group inline dense size="sm" replaces the v-for of q-checkbox/q-radio (same model-value, val,

  display value does not look like an editable input. Keep loading.

- m-date-period: the offset/period q-selects move from before to a q-btn-dropdown flat dense beside the input, or stay but
